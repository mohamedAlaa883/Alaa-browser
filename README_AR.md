# Alaa Deutsch Browser — مشروع أندرويد أولي

متصفح متخصص لتعلّم الألمانية بالفيديو، بواجهة داكنة وشريط بحث وفتح YouTube، مع محاولة إخفاء نتائج الفيديو التي لا يظهر عليها مؤشر ترجمة، وشريط صغير فوق الفيديو للتشغيل/الإيقاف والتحرك 5 ثوانٍ.

## فتح المشروع وبناء APK
1. ثبّت Android Studio على الكمبيوتر.
2. اختر **Open** ثم مجلد `AlaaDeutschBrowser`.
3. انتظر انتهاء Gradle Sync (يتطلب اتصال إنترنت لتنزيل أدوات البناء).
4. من القائمة اختر **Build > Build APK(s)**.
5. ستجد الملف عادةً في `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

## حدود النسخة الأولية — مهم
- هذه نسخة تأسيسية قابلة للبناء من Android Studio وليست APK مبنيًا ومختبرًا هنا.
- فلترة نتائج YouTube تقريبية؛ واجهة YouTube تتغير، ووجود شارة CC قد لا يكون قابلًا للكشف في كل نتيجة. لا يمكن ضمان معرفة وجود ترجمة قبل فتح كل فيديو.
- مواقع الفيديو المحمية أو التي تمنع التشغيل داخل WebView قد لا تعمل كما تعمل في تطبيق YouTube الرسمي.
- استخراج الترجمات التلقائي الكامل، تقسيمها إلى جمل متزامنة، التكرار الذكي عند حدود الجملة، وألوان التحليل النحوي من إضافة الكمبيوتر تحتاج نقلًا وتطويرًا إضافيًا؛ لم يتم الادعاء بأنها مكتملة في هذا الهيكل.
- لا يوجد مفتاح Groq مضمّن. لا تضع مفتاح API سريًا في ملفات التطبيق المنشورة؛ استخدم وسيطًا آمنًا على خادم أو أدخل المفتاح محليًا في نسخة تطويرية.

## الخصوصية
المتصفح يفتح المواقع التي تختارها. لا يحتوي المشروع على خدمة تحليلات أو إرسال بيانات إلى خادم خاص به.
